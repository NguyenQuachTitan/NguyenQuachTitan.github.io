# 🚴 Đạp Xe Hàng Ngày

**Website:** https://nguyenquachtitan.github.io/CyclingToWorkSite

Blog chia sẻ kinh nghiệm đạp xe đi làm hàng ngày, tự bảo trì xe đạp, và review sản phẩm thực tế — viết từ góc nhìn của người dùng phổ thông, không phải vận động viên.

## Nội dung

- 🚵 Trải nghiệm đạp xe đi làm từ 08/2020, hiện tại khoảng hơn 50km/ngày
- 🔧 Hướng dẫn tự bảo trì, sửa chữa xe đạp
- ⭐ Review linh kiện và phụ kiện thực tế
- 📚 Kiến thức cơ bản cho người mới bắt đầu

## Công nghệ

- HTML / CSS / JavaScript thuần
- Hosting: GitHub Pages (miễn phí)
- Không dùng framework
